# Technology Stack: EventFlow

## Frontend Core
- **Framework:** Next.js 15.1.0 (App Router)
- **Library:** React 19.0.0
- **Language:** TypeScript 5.0 (Strict Mode)

## User Interface & Styling
- **CSS:** Tailwind CSS 3.4.1
- **Animations:** Framer Motion 11.15.0
- **Component Library:** Shadcn/UI (based on Radix UI & Lucide React)

## Backend & Services
- **Platform:** Supabase 2.39.7
- **Database:** PostgreSQL (with Row Level Security)
- **Authentication:** Supabase Auth (Email/Password)
- **Storage:** Supabase Storage (for event images and logos)
- **Serverless:** Supabase Edge Functions (Deno)
- **Real-time:** Supabase Realtime (for notifications and status updates)

## Essential Utilities
- **HTTP Client:** Axios (for API interactions)
- **Date Handling:** date-fns (modern date utilities)
- **Feedback:** React Hot Toast (toast notifications)
- **Security:** jsonwebtoken (JWT handling)
- **Identity:** uuid (unique identifier generation)
